## 遇到的问题与解决方式

| 问题 | 原因 | 解决 |
|---|---|---|
| 首次创建 `clarify-first` 写入被取消 | 用户选择并入而非新建 | 改为 task-preflight 第 0 步，避免库里多一个 meta 类重复技能 |
| Python 脚本报 `SyntaxError: invalid character` | heredoc 里中文引号被当作字符串边界 | 改用三引号包裹长文本 |
| `Edit` 工具多次报「string not found」 | 目标文件含不可见字符/全角标点，精确匹配失败 | 改用 Python 脚本做 `replace` + `assert` 断言校验 |
| 新 tag 未进索引 | `skill_info()` 里 tags 硬截 `[:6]`，追加在末尾被静默丢弃 | 把 `clarify`/`questioning` 提到前 6 位 |
| `askill meta` 跳过 pm-meta | 保护机制：不覆盖非 askill 生成的手写技能元 | 手动更新其 SKILL.md，保留 120 条方法索引 |
