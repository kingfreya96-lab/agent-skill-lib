# 项目规则

## 1. 工作日报

当天完成的工作内容，整理成工作日报，记录：
- 完成了什么
- 遇到的问题与解决方式
- 下一步计划

**按项目归档**：在哪个项目做的，日志就记到那个项目，不要堆在单一项目里。项目内存 `<项目>/docs/工作日报/`；Obsidian 同步到对应项目的日志目录（如 `OPC/AI Agent/工作日志/`、`OPC/AI+自媒体/Z 工作日志/`、`OPC/AI觉醒/08-工作日志/`），在对应项目里可查。

## 2. Obsidian 同步

产生新内容（新技能、文档、笔记）时，同步到对应的 Obsidian 文档中：
- 技能库内容 → `OPC/AI Agent/skills/`（用 `askill export --to "/Users/freya/Downloads/Documents/Obsidian Vault/OPC/AI Agent/skills"`）
- 其他内容 → Obsidian Vault 下对应主题目录
- 全局规则 / 记忆层 → `OPC/Agent共享规则/`：真源（`.trae/rules/project_rules.md` / `~/.hermes/memories/MEMORY.md`）改动后，重新同步副本（`00-全局规则.md` 对齐全部规则条目；`01-记忆层-公开版.md` / `02-记忆层-隐私版.md` 对齐记忆真源），避免副本漂移。

## 3. 技能同步到共享库

项目中创建的 skill **需要**同步到共享技能库 `~/.agent-skills/`，保证所有 agent 可用、内容单一来源不漂移。

判定标准：
- **要同步**：通用可复用的 skill（跨 agent 都能用、无厂商专属内容、无敏感信息）
- **不要同步**：厂商专属 skill、含密钥 / 账号 / 代理的 skill、一次性临时脚本

流程：
1. 新建技能后运行 `askill collect --apply` 收编进库
2. 运行 `askill meta` 刷新分类技能元
3. 运行 `askill export` 同步到 Obsidian
4. 运行 `askill doctor` 确认分发无缺口

## 4. 先反问再动手（全局门禁）

**拿到问题不马上执行。** 用户说的 ≠ 用户要的。先多次反问确认意图，再开工。

**3W5H 七问**（挑着问，不必全问）：What（交付的具体东西）/ Why（背后真问题）/ Who（给谁用、谁拍板）/ When（何时要、先后依赖）/ Where（哪份材料、哪个环境）/ How（最省步骤的路径）/ How much（多深、多长、几版）。

**分轮反问**：一轮最多 3 问、最多 3 轮，按依赖顺序推进——
1. 第 1 轮定目标（What + Why）
2. 第 2 轮定边界（Who + When + How much，含「明确不要什么」）
3. 第 3 轮定验收（How + 成功标准、禁止项）

规则：
- 每轮问完就停，等用户回答，不自问自答、不边问边干
- 用户答「随便 / 都可以」→ 给默认值并确认「我按 X 做，行吗」，不继续追问
- 3 轮仍不清楚 → 停止追问，复述 + 给 2 个候选方案让用户选，不开第 4 轮
- 动手前一句话复述：「我理解你要的是【交付物】，用来【目的】，范围是【边界】，做完标准是【验收】。对吗？」

**何时可以不问**：单一事实查询、纯闲聊、指令已明确到只剩执行、用户已给全约束、用户说「别问了先给一版」（此时给最小可用版 + 把假设写在开头）。

**与其他门禁的关系**：第 0 步反问 → 第 1 步预检卡（`task-preflight` 的 5W3H 卡）→ 第 2 步执行。问到的约束必须写进预检卡 `clarifications` 段，问完不记 = 没问。

完整规则见共享技能 `~/.agent-skills/task-preflight/SKILL.md`「第 0 步：先问清」。

## 5. 技能只读原则

技能库 `~/.agent-skills/` 里的技能，**除了 Freya 自己创建的可以编辑修改，其他一律只读不修改**。

- **可编辑**：Freya 自建 / 沉淀的技能（如 task-preflight、手写的 pm-meta 等）
- **只读**：第三方导入、厂商专属技能（正文逻辑、内容都不动）
- **例外**：经 Freya 授权的「描述去重 + disambiguation 段」元数据整理，可改 frontmatter `description` 与顶部区分段，其余正文仍只读

## 6. 共享规则必读（所有 agent）

全局规则与记忆层单独存放在 Obsidian `OPC/Agent共享规则/`，是**所有 agent 的共享记忆**，agent 直接读、不需要各自整理：

- `00-README.md` — 目录索引
- `00-全局规则.md` — 全局规则同步副本
- `01-记忆层-公开版.md` — 共享记忆（所有 agent 可读）
- `02-记忆层-隐私版.md` — 隐私记忆（密钥 / 私人经历，仅特定任务下读）

**每个 agent 开工前必读**公开版内容。真源改动后重新同步到本目录，别在各 agent 处复制。
